อัปเดต Google Apps Script ให้ซิงค์สมบูรณ์

เนื่องจากสคริปต์บนคลาวด์ของ Google ยังเป็นเวอร์ชันเดิมที่ติด Error "คอลัมน์เริ่มต้นของช่วงมีค่าอยู่นอกช่วง" ทำให้ไม่สามารถเขียนข้อมูลลงชีตได้
ท่านเพียงทำตาม 3 ขั้นตอนง่ายๆ ด้านล่างนี้ (ใช้เวลา 1 นาที) ระบบจะซิงค์สมบูรณ์ทันทีครับ

กำลังตรวจสอบสถานะสคริปต์บน Google...
1

คลิกปุ่มเพื่อคัดลอกโค้ดใหม่ทั้งหมด

คลิกปุ่มนี้ 1 ครั้ง ระบบจะคัดลอกโค้ดตัวแก้ไขล่าสุดที่ไม่มี Error เข้าสู่คลิปบอร์ดของคุณทันที

🔗 เปิด Google Sheet ของคุณ

✅ คัดลอกโค้ดเรียบร้อยแล้ว! นำไปวางใน Google Apps Script ได้เลยครับ

📖 ขั้นตอนการวางโค้ดใน Google Sheet (ทำตามรูปด้านล่าง)

2.1

เปิดหน้าต่าง Apps Script

ในหน้า Google Sheet ที่เปิดขึ้นมา ให้มองที่แถบเมนูด้านบน แล้วคลิกที่ ส่วนขยาย (Extensions) ➔ Apps Script

2.2

วางโค้ดใหม่ทับโค้ดเดิม

1. คลิกเมาส์ในช่องพิมพ์โค้ด
2. กดแป้นพิมพ์ Ctrl + A (เพื่อเลือกโค้ดเดิมทั้งหมด)
3. กดแป้นพิมพ์ Ctrl + V (เพื่อวางโค้ดใหม่ที่เพิ่งคัดลอกมา)
4. กดปุ่มรูปแผ่นดิสก์ 💾 (บันทึก / Save) ที่แถบเครื่องมือด้านบน

2.3

กดปรับใช้เป็น "เวอร์ชันใหม่" (สำคัญที่สุด ⭐)

1. คลิกปุ่มสีน้ำเงินมุมขวาบน: ทำให้ใช้งานได้ (Deploy) ➔ เลือก จัดการการทำให้ใช้งานได้ (Manage deployments)
2. คลิกที่ไอคอนรูป ดินสอ ✏️ (แก้ไข / Edit) ที่มุมขวาบนของป๊อปอัป
3. ตรงช่องหัวข้อ เวอร์ชัน (Version) ให้คลิกเปลี่ยนเป็น "เวอร์ชันใหม่" (New version)
4. กดปุ่มสีน้ำเงิน "ทำให้ใช้งานได้" (Deploy) ด้านล่าง ➔ กด เสร็จสิ้น (Done)

3

กลับมาที่โปรแกรมและกด "ซิงค์ขึ้นชีททันที"

เปิดโปรแกรมบันทึกเวลา ➔ เปิดหน้าต่าง กำหนดเวลาทำงานและรายชื่อพนักงาน ➔ กดปุ่มเขียว "🔄 ซิงค์ขึ้นชีททันที"
เพียงเท่านี้ รายชื่อคุณ tqq (777), qqq (AD11) และพนักงานทุกคนจะเข้าไปปรากฏใน Google Sheet ทันทีครับ!

🔍 ดูโค้ดทั้งหมดด้วยตนเอง (หากปุ่มคัดลอกด้านบนไม่ทำงาน สามารถคัดลอกจากกล่องนี้ได้)
