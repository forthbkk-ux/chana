# TimeTrack Pro - ระบบแดชบอร์ดบันทึกเวลา เข้า-ออก งาน

ระบบบันทึกเวลาทำงานและแดชบอร์ดสรุปสถิติแบบ Responsive HTML5 รองรับการเปิดใช้งานบนมือถือ ไอแพด/แท็บเล็ต และคอมพิวเตอร์

## จุดเด่นของระบบ
- **เปิดใช้งานได้ทันที**: เพียงดับเบิลคลิกไฟล์ `index.html` ไม่ต้องติดตั้ง Node.js หรือเซิร์ฟเวอร์
- **รองรับทุกหน้าจอ (Responsive)**:
  - **มือถือ**: ปรับเป็นเมนูการ์ดแนวตั้ง มีปุ่มนำทางด่วนด้านล่าง (Bottom Navigation)
  - **ไอแพด**: กริด 2 คอลัมน์ แยกสัดส่วนระหว่างแผงตอกบัตรและสถิติภาพรวม
  - **คอมพิวเตอร์**: แดชบอร์ดเต็มรูปแบบ พร้อมตารางประวัติ ระบบค้นหา และส่งออกข้อมูล
- **คำนวณสถานะอัตโนมัติ**: แยกแยะ "ตรงเวลา" หรือ "มาสาย" ตามเวลาเริ่มงาน (ค่าเริ่มต้น 08:30 น.)
- **สถิติ & กราฟ**: กราฟวงกลมสรุปรายวัน และกราฟแท่งแนวโน้มการเข้างานย้อนหลัง 7 วัน
- **บันทึกข้อมูลถาวร**: ข้อมูลจะถูกเก็บไว้ในเครื่อง (LocalStorage) ไม่สูญหายเมื่อปิดหน้าเว็บ
- **ส่งออก Excel (CSV)**: รองรับภาษาไทยสมบูรณ์ (UTF-8 with BOM)

## รายการไฟล์ในโฟลเดอร์
- `index.html` : หน้าเว็บหลัก
- `style.css` : ไฟล์สไตล์ตกแต่ง Responsive และรูปแบบสำหรับการพิมพ์รายงาน (Print)
- `app.js` : ระบบคำนวณเวลา จัดการข้อมูล กราฟ และเสียงแจ้งเตือน
